# Як ми використали ШІ

## Інструмент і мета

Codex допоміг підготувати україномовний README й документацію до Завдання 2. З його допомогою ми звірили сценарій із чинним демо, структуру звіту з форматом організаторів і перерахували прогноз економії часу. Для цієї роботи використано вигадані записи, публічні вимоги й код статичного прототипу.

## Рішення команди

Команда обрала користувачами виконавців заходів та уповноважених, які подають і перевіряють докази. Ручне зведення таблиць і документів ускладнює контроль строків та пошук підтверджень. Тому в прототипі команда зосередилася на одному реєстрі й відтворюваному сценарії перевірки. Прострочення визначає явне правило порівняння дат, а повернення чи підтвердження залежить від дії уповноваженого. Уся логіка демо працює в браузері без ШІ-сервісів. [Правила прототипу](architecture.md)

## Розглянуті варіанти

- **React із Vite.** Для одного екрана реєстру команда обрала HTML, CSS і JavaScript. React із Vite додав би збірку та налаштування базового шляху на GitHub Pages.
- **Збереження в `localStorage`.** Стан між сеансами міг би залишити попередні рішення на спільному пристрої. Команда обрала стан у пам’яті, щоб кожне перезавантаження відтворювало той самий початковий реєстр.
