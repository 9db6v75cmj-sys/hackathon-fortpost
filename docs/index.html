Як працює моніторинг

  1. Запланувати

    Визначити захід, відповідальний підрозділ, строк та індикатор виконання.

  2. Подати доказ

    Додати підтвердження того, що захід виконано.

  3. Перевірити

    Переглянути доказ і підтвердити захід або повернути його на доопрацювання.

  4. Підбити підсумки

    Побачити, скільки заходів підтверджено й скільки прострочено.
